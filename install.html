安装到桌面

不下载安装包，不占手机空间，一键打开更像 App

为什么推荐这样做？安装后图标会出现在桌面或主屏幕，点开就是全屏工具页，不用每次翻浏览器书签；同时页面资源会被缓存，弱网或断网时也能打开。

选择你的设备
  1. 电脑 · Chrome / Edge
  2. Android 手机 / 平板
  3. iPhone / iPad
  4. 安装后能做什么

1. 电脑 · Chrome / Edge

  • 用 Chrome 或 Edge 打开 工具页；
  • 看地址栏最右侧，如果出现一个「安装」图标（显示器带向下箭头），直接点它；
  • 找不到图标时，点浏览器右上角「⋮」菜单 → 「安装小有计划」或「应用 → 将此站点作为应用安装」；
  • 确认后，桌面和开始菜单会出现独立图标。

2. Android 手机 / 平板

  • 用 Chrome 打开 工具页；
  • 点右上角「⋮」菜单；
  • 选择「添加到主屏幕」或「安装应用」；
  • 确认后，主屏幕上会出现小有计划的图标。

3. iPhone / iPad

请务必使用 Safari 浏览器（微信内置浏览器、Chrome for iOS 不支持此功能）：

  • 用 Safari 打开 工具页；
  • 点屏幕底部中央的「分享」按钮（方框带上箭头）；
  • 在弹出的列表中向下滑，选择「添加到主屏幕」；
  • 右上角点「添加」，图标就会出现在主屏幕。

小提示：iOS 上的网页应用在长时间不使用后，系统可能清理站点数据。请务必定期用工具页的「导出」功能备份一份 JSON 文件。

4. 安装后能做什么

  • 从桌面或主屏幕直接打开，无需输入网址；
  • 以独立窗口运行，没有浏览器地址栏，界面更清爽；
  • 页面资源已缓存，断网或弱网时也能正常打开；
  • 你的计划数据仍然保存在本机，安装不会改变这一点。

说明：这是一个可安装的网页应用（PWA），不是应用商店里的原生 App。因此它不会请求通知权限，也暂时没有推送提醒能力。
