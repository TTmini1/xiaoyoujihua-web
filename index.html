常见问题

你可能想知道

如果这里没有你要的答案，欢迎直接联系我们。

免费版有什么限制？

清单数量、标签数量都不限制，全部功能免费用，不需要绑定支付方式，也不需要注册账号。

我的计划数据存在哪里？

存在你当前使用的这个浏览器里（浏览器本地存储）。我们没有任何服务器，也不需要你注册账号，所以你的计划内容不会离开这台设备，我们看不到也拿不到。

没有网络时还能用吗？

可以，而且完全不受影响。因为数据就在本机，断网时照常记录、勾选和删除，联网后也不需要做任何同步操作。

换手机或换电脑，数据会跟着走吗？

目前需要手动搬一次：在原设备点「导出」下载一个 JSON 文件，在新设备点「导入」把它选进来，计划就完整过去了。云端多端同步正在开发中，上线后这一步就不需要了。

数据会不会丢？我该怎么备份？

浏览器本地存储可能因为清理浏览器数据、使用无痕模式或系统自动清理而丢失，所以我们强烈建议你定期点「导出」保存一份 JSON 备份，它同时也是换设备迁移的方式。

能和朋友或同事协作同一份计划吗？

暂时不能。共享清单、成员权限这些需要云端账号体系，属于规划中的能力，目前还没有实现。
